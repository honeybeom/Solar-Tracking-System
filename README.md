# Uno Solar Lab — NEMA17 CAD 기준 시뮬레이터

브라우저에서 Arduino Uno 스타일 코드를 실행해 2축 태양광 추적기, LCD, INA219 전력 측정, 탄소 저감량을 검증하는 졸업작품 시뮬레이터입니다.

현재 버전은 제공된 CAD 자료를 기준으로 **NEMA17 스테퍼모터 2개 + 30:1 웜기어 + 155 mm 회전 베어링** 구조를 사용합니다.

## CAD 반영 치수

| 구성품 | 시뮬레이터 기준 |
| --- | --- |
| 태양광 패널 | 5 W, 215 × 180 mm |
| 수평/수직 구동 | NEMA17 (42 × 59.2 × 42 mm) 2개 |
| 감속기 | 30:1 웜기어 |
| 회전 베어링 | 155 × 155 × 10 mm |
| LCD1602 I²C 모듈 | 82 × 36 × 20.6 mm |
| 베이스 | 200 × 200 mm 아크릴 기준 |

Inventor `.iam/.ipt` 조립체는 브라우저에서 직접 표시할 수 없으므로, 포함된 STEP/STL 자료에서 확인한 외형과 치수를 경량 3D 모델 및 충돌 상자에 적용했습니다.

## Arduino 하드웨어 연결

| 기능 | Uno 핀 / 주소 |
| --- | --- |
| CdS LDR | A0 좌상, A1 우상, A2 좌하, A3 우하 |
| NEMA17-H 드라이버 | STEP D2, DIR D3 |
| NEMA17-V 드라이버 | STEP D4, DIR D5 |
| LCD1 / LCD2 | I²C 0x26 / 0x27 (A4/SDA, A5/SCL) |
| INA219 | I²C 0x40 |

기본 스케치는 `AccelStepper`의 STEP/DIR 모드로 작성되어 있습니다.

```cpp
AccelStepper motorH(AccelStepper::DRIVER, 2, 3);
AccelStepper motorV(AccelStepper::DRIVER, 4, 5);
const float STEPS_PER_DEG = 133.333;
```

`STEPS_PER_DEG`는 1.8° NEMA17, 1/8 microstep, 30:1 웜기어 기준입니다.

`200 × 8 × 30 ÷ 360 = 133.333 step/°`

실제 드라이버의 microstep 점퍼 설정이 달라지면 이 값도 같이 바꿔야 합니다.

## 작동 순서

1. 5초 동안 추적 전 전력을 평균내 LCD1에 고정합니다.
2. 네 LDR의 좌우/상하 오차로 NEMA17-H/V를 1° 단위로 이동합니다.
3. 10회 연속 정렬되면 30초 안정화합니다.
4. 5초간 추적 후 전력을 평균내 LCD2에 표시합니다.
5. 이후 LCD2에서 전력 증가율과 누적 Wh·CO₂ 저감량을 교대 표시합니다.

빛 세기는 85%로 고정되어 있으며, 빛 방향과 높이(90~160°)만 조절할 수 있습니다.

## 3D 기구 검증

패널의 회전된 외곽 형상을 베이스, 155 mm 베어링, 알루미늄 기둥, NEMA17-H/V 및 웜기어 하우징과 비교합니다. 각 항목의 최소 근사 간격(mm)을 표시하며, 충돌하는 스테퍼 위치 명령은 시뮬레이터에서 차단됩니다.

이는 STEP/STL 외형을 바탕으로 한 1차 공간 검토입니다. 실제 제작 전에는 모터 드라이버, 배선, 나사, 브래킷 및 웜기어 백래시를 포함해 최종 CAD와 실물로 검증해야 합니다.
